# 🏠 NyumbaSense-ml
### *Making sense of house prices.*

NyumbaSense is a machine learning project that predicts residential 
property prices in Kenya using real listings from BuyRent Kenya.

## 🎯 Objective
To build an accurate, interpretable model that estimates house prices 
based on location, property type, size, amenities, and surroundings.

## 📊 Dataset
- Source: BuyRent Kenya
- Size: 600+ residential listings
- Features: Price, Property Type, Location, Bedrooms, Bathrooms, 
  Size, Amenities, Surroundings

## 🧠 Models
- Linear Regression (baseline)
- Random Forest
