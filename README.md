# NyumbaSense-ml
### *Making sense of house prices.*

NyumbaSense is a machine learning project that predicts residential property
prices in Kenya from property listing details on BuyRent Kenya.

**Student:** Kennedy Kariuki Maina (DDA-03-0116/2025)
**Programme:** Diploma in Data Science and Analytics, Zetech University
**Methodology:** CRISP-DM

## Objective
To build a model that estimates house prices from location, property type,
size, bedrooms, bathrooms, amenities and surroundings.

Specific objectives:
- Analyse the distribution and characteristics of house prices in Kenya.
- Identify the features that influence house prices.
- Develop and evaluate machine learning models for price prediction.
- Compare the performance of different algorithms.

## Dataset
- **Source:** BuyRent Kenya property listings (houses, townhouses and villas for sale)
- **Size:** 9,000 records, made up of **800 original scraped listings and 8,200
  synthetic records** generated by an AI agent
- **After cleaning:** 8,978 records (duplicates and listings with no price removed)
- **Raw columns:** Title, Property Type, Price, Location, Bedrooms, Bathrooms,
  Size, Amenities, Surroundings, Created At, URL, Record Type

> **Note:** about 91% of the data is synthetic and many rows share identical
> property details. This can make model scores look better than they would be
> on new real listings. See [Modeling](#modeling) for how this was handled.

## Data cleaning
- Removed duplicate rows and listings with "Price not communicated"
- Converted price, bedrooms and bathrooms from text to numbers
- Converted size from mixed units (sqm, sq ft, acres) to square metres
- Set unrealistic sizes (under 30 sqm or over 100 acres) to missing, and added
  `size_missing` and `bathrooms_missing` flags
- Split `location` into `area` and `sub_location`
- Added data quality flags for price outliers, size outliers and listings with
  more bathrooms than bedrooms + 2

## Key findings from EDA
- Price is right-skewed (median about KSh 70M, mean about KSh 83M), so the models
  predict `log(price)`.
- Location drives price: median price by area ranges from about KSh 10M
  (Kitengela, Ngong) to about KSh 137M (Karen).
- Villas are the most expensive (median about KSh 95M), then townhouses (about
  KSh 74M), then houses (about KSh 35M).
- Size, bathrooms and bedrooms are positively correlated with price (Spearman
  0.59, 0.52 and 0.51).
- Size is missing for 47% of rows.

## Modeling
Four models are compared:

1. Dummy Regressor (baseline, predicts the median)
2. Linear Regression
3. KNN Regressor (k = 7)
4. Random Forest Regressor (200 trees)

**Steps**
1. Remove rows with identical property details (8,978 to 6,098 rows) so that a
   copy of a test row is not in the training set.
2. Turn amenities and surroundings into 0/1 columns and one-hot encode property
   type, area and sub location (164 features).
3. Use `log(price)` as the target and convert predictions back to KSh.
4. Split 80% train and 20% test, fill missing size and bathrooms with the
   training median, and scale the features for Linear and KNN.

**Metrics:** MAE, RMSE, median % error and R². Errors are in KSh millions.

## Results
| Model | MAE (KSh M) | RMSE (KSh M) | Median % error | R² |
|---|---|---|---|---|
| Dummy | 52.2 | 71.4 | 60.7% | -0.05 |
| Linear Regression | 24.9 | 45.2 | 24.8% | 0.58 |
| KNN | 14.7 | 34.2 | 10.9% | 0.76 |
| **Random Forest** | **13.6** | **34.0** | **10.2%** | **0.76** |

- All three real models beat the Dummy baseline.
- Random Forest and KNN perform almost the same. A typical prediction is about
  10% away from the listed price.
- Linear Regression is the weakest because price does not change in a straight
  line with size and location.
- The gap between MAE and RMSE shows that a few expensive houses are predicted
  badly.

## Limitations
- Most of the data (about 91%) is synthetic, so results may not match how the
  models perform on new real listings.
- Size is missing for almost half of the rows and is filled with the median.
- Prices are asking prices from listings, not final sale prices.
